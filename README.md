# SonoMap thesis (web edition)

Markdown transcription of *High-Dimensional Audio Feature Extraction for Music Similarity Visualisation* (Jakov Kačan, Algebra Bernays University, 2026), for GitHub Pages.

## Publish
1. Push this folder's contents to the root of a GitHub repository (for example `sonomap-thesis`).
2. Repository **Settings → Pages → Build and deployment → Deploy from a branch**, branch `main`, folder `/ (root)`.
3. The site is served at `https://<username>.github.io/<repository>/`.

Equations are rendered client-side by MathJax 3 (loaded at the top of `index.md`); kramdown passes `$$…$$` through as math.
